# Game Pacing

A night must have a **power curve**. Fifteen identical 10-point quiz cards are a design failure.

## Emotional arc

```text
WELCOME → CURIOSITY → EASY SUCCESS → COMPETITION
→ LAUGHTER → SURPRISE → RIVALRY → POWER-UP
→ COMEBACK → CHAOS → BIG FINAL → CELEBRATION
```

## Round bands (Reyes y Profetas)

| Rounds | Job | Stakes |
|---|---|---|
| 1–3 | Discovery, easy, fast, low stakes | Learn the buzzer |
| 4–6 | Competition appears | First rewards, team heat |
| 7–10 | Harder, physical, streaks | Comeback tools |
| 11–13 | Chaos, more interaction | Higher value |
| 14 | Semi-final intensity | Everything matters |
| 15 | Finale | Different background, bigger stakes, podium |

Alternate thinking / movement / laughter. Never five seated quiz questions in a row.

## Finale rule

Round 15 is not "question 15, worth 10 points."
It must feel materially larger: illustration, stakes, reveal, celebration.

## Implemented

Team screens show the band name (Descubrimiento → Gran final). YAML already encodes rising points and a 25-point finale. Taboo plays as talk. The harp hunt plays as movement. Kings order is a tap sequence. Freeze is a real stop. Prophets is a shout. Solomon is a judgment the room casts. Jonah at home is a three-beat path, not a quiz. Round 15 is a stand-up crown slam; the presenter’s ¡La corona! opens the ceremony. Crossing a rank is a POWER-UP: Sois Rey, next correct ×2. No hosted leftover cards.

## M1 pacing

M1 ships one real peak (first buzz + reveal + score) inside a short night. The YAML lists a full 15-round curve so later slices fill the bands instead of inventing a new shape.
