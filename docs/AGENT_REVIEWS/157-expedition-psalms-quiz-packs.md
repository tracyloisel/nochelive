## 1 — Game experience

Boucle Street : anticipation → choix → révélation → correction courte →
progression visible → prochaine question. Chaque pack commence par trois
lectures faciles, ouvre ensuite contexte et tensions, puis termine par une
question canonique, spirituelle ou de transfert. Six portes restent libres.

Le Psaume 149 n'est pas un QCM : rencontre calme, droit au silence, aucune
bonne réponse. Les deux questions sur le Psaume 137 sont non notées.

## 2 — UI design

Contrat éditorial seulement : question ≤ 72 graphèmes, réponse ≤ 32,
correction ≤ 120, quatre réponses maximum. Le rendu réel n'a pas encore été
intégré ni inspecté ; aucune validation visuelle de production n'est revendiquée.

## 3 — Art direction

À produire après validation éditoriale. Les récompenses symboliques donnent un
point de départ, pas des artworks approuvés.
